# Synth contracts — agreed before worker implementation

Namespace: BudgetGameDev.Synth. Paths below are relative to the package root `LocalPackages/com.budgetgamedev.procedural-synth`. Portable package `com.budgetgamedev.procedural-synth` version `0.1.0`, requiring Unity `6000.5.10f1` or later in the supported 6.5 line, with isolated Runtime/Editor/Tests assemblies; no changes to existing gameplay. Manager owns contracts, SynthEngine, composition, tests and integration docs. Voice worker owns Core/MonoVoice.cs and voice primitives only. Nonlinear worker owns Core/Nonlinear.cs only. Unity worker owns Runtime/Unity/*.cs and Editor/SynthDemoBuilder.cs only. Shared changes require manager coordination. All runtime DSP state must be unmanaged structs, no allocation in rendering; Unity.Mathematics + fixed buffers allowed. No managed references in DSP.

## Runtime contracts
SynthParameters is a serializable value struct (manager owned). Three OscillatorParameters (Waveform enum Sine/Saw/Square/Triangle/Wavetable; Octave -3..3; Semitone -12..12; Cents -100..100; Level 0..1). SubLevel and NoiseLevel 0..1. Sub reference is played/gliding note minus 12 semitones, independent of oscillator tuning. DriftCents 0..5. EnvelopeParameters Attack/Decay/Release seconds .001..10; Sustain 0..1. CutoffHz 20..18000 limited further by rate; Resonance 0..0.95; PreDrive 1..12; PostDrive 1..6; OutputGain 0..1; FilterEnvelopeOctaves -4..6; GlideSeconds 0..2; PhaseModCycles 0..0.5; EnvelopePhaseModCycles 0..0.5; CutoffModOctaves 0..3; WavetablePosition 0..1. Legato, ResetPhase bool; NotePriority enum Last/Low/High. Every externally supplied float sanitized including NaN/Infinity. Parameters smoothed over ~5ms within voice, except flags/envelope times applied on next sample. Glide exponential pitch-domain with stated time convention.

MonoVoice.Initialize(int sampleRate,uint seed,SynthParameters parameters), SetParameters(in SynthParameters), NoteOn(int midi,float velocity), NoteOff(int midi), AllNotesOff(), float ProcessSample(). Read-only CurrentNote, CurrentPitch (MIDI), AmpLevel. Own sample rate internally. Supported output rates 32000..96000. Handles all 128 MIDI keys via bounded fixed storage; duplicate note-on replaces existing key; note-off removes that key; no sustain pedal in first version. Inactive note release must not retrigger. Last key release releases envelopes. Free-running oscillator phases even when silent; explicit reset option. Fixed route evaluation osc2/osc3 -> osc1 phase modulation (cycles, not FM) and filter cutoff (octaves), filter envelope changes PM depth; no circular routes.

NonlinearFilter24.Reset(); float Process(float input,float cutoffHz,float resonance,float sampleRate). Four pole nonlinear lowpass; documented topology and feedback delay/solver. Saturation.SoftClip(float), DcBlocker.Reset(), float DcBlocker.Process(float input,float sampleRate). No hidden allocation. Voice worker owns oversampling/decimation integration, consult nonlinear worker. Begin 2x or 4x with real low-pass decimator; measure against 1x before acceptance.

SynthEvent { long Sample; SynthEventType Type (NoteOn,NoteOff,AllNotesOff,Parameter); int Note; float Value; SynthParameterId Parameter; }. Sample absolute frame on engine-local clock starting at initialization, not Unity dsp ticks. Parameter event changes one scalar target. SynthEngine.Initialize(int sampleRate,uint seed,SynthParameters), bool Enqueue(in SynthEvent), void SetParameters(in SynthParameters), float ProcessSample(), long SamplePosition, int DroppedEvents, int LateEvents; properties VoiceNote, VoicePitch, AmpLevel. Preallocated sorted fixed capacity 128 events, stable same-time insertion. Events <= current sample applied before rendering sample; late counter incremented upon enqueue. Max 128 events/sample. Overflow drops incoming event, increments counter, requests all-notes-off on next sample (stuck-note protection). Preset updates are value copies transported through pipe and smoothed by voice. Adapter bounds messages and retains/retries failed sends; never drops note releases silently.

Unity adapter uses installed UnityEngine.Audio IAudioGenerator / GeneratorInstance.IRealtime / IControl and Pipe, not com.unity.pipeline (CLI tooling only). Engine unmanaged state owned in realtime struct; configure owns initialization, no shared disposal race. Mono output for AudioSource mixer and spatializer routing. WebGL unsupported by SAP per official 6.5 manual; explicit disabled adapter on Web, no silent fallback claim. Rate/device reconfiguration resets voice and timeline, control reschedules from fresh epoch. Native desktop is intended; macOS verification first.

## Acceptance gates
M0: actual Unity compilation, generator nonzero signal at AudioSource and AudioListener, mixer attenuation measured, stop/start and reconfigure no errors. Saved isolated demo scene.
M1: deterministic seed; sample exact event offset; overlapping notes/all priorities/legato/retrigger/release/glide; finite <=1 peak under range stress at 32/44.1/48/96k; processing 0 managed allocations after warmup; 1024-frame p95 <25% buffer duration in measured configuration. WAV heavy and cleaner loudness-matched renders for human review (no claimed listening validation).
M2: initial audio-rate routes, table mipmaps and morphing only after M1 technical checks; contrast presets; measured high-frequency alias/oversampling comparison, report limitations.
M3: repeatable seeded event schedule with tempo/scale/rest/accent/phrases; bounded game-state mappings, immediate smoothing vs beat/phrase changes and hysteresis; automation tests and render.
M4: explicitly deferred pending human listening feedback and CPU/alias measurements; do not equate feature breadth with sound quality.

## Package integration contract

Runtime files live under `Runtime/Core`, `Runtime/Composition`, and `Runtime/Unity`; DSP interfaces and parameter units are unchanged by packaging. The importable demo lives under `Samples~/MonoSynth`, and Unity imports version 0.1.0 into `Assets/Samples/Procedural Synth/0.1.0/MonoSynth`. The builder writes `Assets/ProceduralSynthDemo/MonoSynthDemo.unity`. Default routing is AudioSource to AudioListener; consumers may assign an AudioMixerGroup. No BROcoli assets or gameplay packages are required. Offline tools and documentation live under `Tools~` and `Documentation~`. The initial worker ownership descriptions above record implementation coordination, not restrictions on consuming the package.
