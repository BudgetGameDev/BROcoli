Fog Particles 1.0.0 by Game Seed Assets
https://assetstore.unity.com/packages/vfx/particles/fog-particles-351840

Free Fire VFX - URP 1.0.2023.1 by Vefects
https://assetstore.unity.com/packages/vfx/particles/fire-explosions/free-fire-vfx-urp-266226

URP Stylized Water Shader - Proto Series 1.0 by BitGem
https://assetstore.unity.com/packages/vfx/shaders/urp-stylized-water-shader-proto-series-187485

Stylized Water Effect Pack 1.0 by Namu
https://assetstore.unity.com/packages/vfx/particles/stylized-water-effect-pack-270114

These four packs ship shaders written for Universal only, so the game no longer
draws through them: the water, the fire, the fog and the spray now use BROcoli's
own shaders, which compile for both pipelines. The packs remain
licensed dependencies and their textures, meshes and particle definitions are
still used; only the shading path changed.
