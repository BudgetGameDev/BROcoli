# Changelog

All notable changes to this package are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this package
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Deterministic multi-room dungeon, cave, plains, forest, mountain, and desert
  environment bands with theme-owned platform boundaries.

### Changed

- Dungeon edges now use low masonry railings, while cave edges use grounded rock
  dressing and the remaining themes expose safe asset-ready boundary hooks.
- Procedural rocks and authored props stay fully supported by generated floor
  instead of clipping past an edge or floating outside the platform.

## [0.1.0] - 2026-08-30

### Added

- Initial extraction from the single-game BROcoli project into a local package.
