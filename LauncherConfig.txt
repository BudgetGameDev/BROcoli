# =============================================================================
# Launcher configuration
# =============================================================================
#
# Read by the game hub when the launcher opens. Every setting is optional, and
# with all of them commented out -- the default below -- the launcher shows its
# scrollable list of installed games. That is the normal behaviour; this file
# only exists so a build can deviate from it.
#
# Format: one "key = value" per line. Blank lines are ignored, and everything
# after a '#' is a comment. Unknown keys are reported and skipped, so a typo
# shows up in the console instead of silently doing nothing.
#
# This file is committed, so whatever it says applies to everyone who checks
# the branch out. Keep it empty on shared branches unless the whole team wants
# the same startup behaviour.
#
#
# -----------------------------------------------------------------------------
# startupScene
# -----------------------------------------------------------------------------
#
# Opens this scene instead of the game list, once, the first time the launcher
# opens in a run. Use it for a single-game build, or to skip the picker while
# iterating on one game.
#
# Leaving the launcher from inside a game still shows the list, so the other
# games stay reachable -- the scene is only forced on the first open.
#
# The value is a scene NAME, not a path and not a game id, and that scene must
# be in the build. A misspelled or removed scene is reported and ignored: the
# launcher falls back to the game list rather than failing to open. When the
# scene belongs to a registered game, that game's setup is applied first, so it
# starts exactly as if it had been picked by hand.
#
# Uncomment one of these to boot straight into BROcoli:
#
# startupScene = Brocoli_Dungeon
# startupScene = Brocoli_MainMenu
